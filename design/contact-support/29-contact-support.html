Try again
The one usually skipped, and the one that matters most: a support form that can’t send is a dead end. So it names the cause — transport, not their input, so they don’t reword a message that was fine — and offers exactly one way through. Retry, because it’s the only action that can actually succeed: there is no support address to fall back to yet (#374), and a second button would imply a choice where there is none. The reference is issued here, before the send succeeds, which is what lets a failed message still be something they can ask about.

Each of these turns a send-and-confirm surface into something that stores and tracks conversations — its own product, with its own data model and its own answer to “who owes a reply.” The confirmation says we’ll email you precisely so nobody comes back here looking for a status.
