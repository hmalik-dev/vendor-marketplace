What came out, and where it went
The seven-row fee table and the three availability cards are gone. The fee table said $0 six times to make one point the hero’s reassurance row already makes in nine words; availability became one sentence under the payout steps. Both live in full in the vendor agreement, which is linked twice. A quick page earns its length by not repeating itself.
The commission now appears once
As a subtraction inside the worked example, where the result is what you keep. Dropping the fee table removed the second occurrence, which is an improvement rather than a loss — the rule was always that it must never read as a bare display numeral.
Unchanged: routing, CTA count, color
Three entries, one destination; #payouts still anchors the second section. Start taking bookings twice only, hero and closing band. Sage on You keep, gold on both config chips because both name a wait, no red anywhere.
